## Easy-to-undo defaults taken since last Tuesday

- **Typing together keeps its key away from the server** (2026-10-30, agents + multiplayer step 20). The first person in a page makes the room's key in their own browser; anyone who joins gets it handed over, locked for them alone; an agent can only join a room a person already has open. The server only passes on scrambled messages and stores nothing. It protects against anything that reads the server's traffic, not against a changed server (that serves the editor itself). ➡️ Keep it.

- **Without "Pins go to", the helper starts Claude Code** (2026-10-30, after your preview note removing the choice; agents + multiplayer 16 and 50). Another agent can be named in the helper's start command. Pins go to whichever connected agent takes them first. ➡️ Keep it.

- **Stop in the MCP menu stops an agent in this browser** (2026-10-29, agents + multiplayer step 12). Each connected agent has its own Stop. It holds in the browser where you press it; an agent working through another browser or device, or one that reconnects under a new name, keeps going. Making Stop hold everywhere needs a server change. ➡️ Keep it for now (ask if you want Stop to hold everywhere).
