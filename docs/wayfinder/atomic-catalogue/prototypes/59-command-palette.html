Command palette and Keyboard shortcuts mock-up for Tuesday 10 Nov

Ctrl K opens the command palette: one search box that finds pages, files, components and anything you can do right now. Its Shortcuts button (or the ? key) opens the list of every keyboard shortcut. Nothing about how they work changes. After rebuilds both from the approved parts, so the two windows share one box, one heading style and one row.

Today: the palette and the shortcuts list each draw their own window, headings, close button and rows.

After: 2 window copies become 1 · 2 heading styles become 1 · 2 row heights become the one 32 px row · 5 odd gap sizes snap to the shared spacing · hover only with a mouse.
