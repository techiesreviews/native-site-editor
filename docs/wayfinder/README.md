# Wayfinder maps

One folder per map, `docs/wayfinder/<map>/`: its tickets in `tickets/` and its build's in
`build/tickets/` (`maps` in `scripts/agents/kit.json`). Run `scripts/agents/kit rulebook` for how a
map goes from idea to tickets, and `scripts/agents/kit brief <ticket>` for the brief that hands one ticket to a T3 helper thread.
