# Optional slots in the native preview

`createNativePreview` mounts the editor-only `mountSlotGhosts(pane, frame, options)` overlay. `NativePreviewHandlers.onSlotGhostFill?: (target: SlotGhostFillTarget) => void` is an optional leaf callback. Main does not yet connect this callback to source editing or Undo.

The exported target has `context`, `pagePath`, `tag`, `templatePath`, `hostNode: number[]`, and `name`. It identifies a page-authored custom-element instance and a slot name, never an individual outlet. The root adapter must capture and recheck the source text/revision, current preview context, mapped page/component, and exact instance before calling the separately owned guarded `fillInstanceSlot` seam. Do not use `occurrence` to create independent same-name assignments.

Runtime `slot-ghosts` messages contain `report: SlotGhostReport | null`. Reports contain the target fields (except `name`), a real `hostRect`, and `entries: { name, occurrence, slotNode, assigned, hidden, rect? }[]`. Occurrences are zero-based within each name. Node arrays use source element-child indexes excluding legacy injected styles. Rectangles are iframe viewport CSS pixels. The host validates bounded paths, strings, counts, finite consistent rectangles, context, active page, and tag-to-template mapping before showing controls; every click rechecks current state. An outlet is hidden only when its own or ancestor styles or slot conditions hide it. A normal `display:contents` slot with no client rectangle is visible; zero geometry alone never means hidden. Optional `rect` comes only from positive measurable slot geometry, never a wrapper or guessed rectangle. The UI is rail-only. Hidden and zero-sized empty outlets remain available in the Empty slots rail. Same-name outlets share one button with an outlet count and a first-outlet notice. Browser assignment goes only to the first same-name outlet in tree order; the notice identifies a hidden first outlet even if later outlets are visible. Hyphens become spaces in labels; exact-name hints distinguish case-sensitive names. Fallback content does not count as assignment.

Only real slots in the selected component's shadow root are reported. Selection within a page-authored component resolves that component instance. A component authored inside another template has no exact page-source instance and produces no report. Invisible, zero-sized, offscreen, disconnected, or standalone-template hosts produce no controls. Reports update on selection, rendering, slot changes, scrolling, resizing, and page DOM changes, coalesced once per animation frame. The callback reads the current selection and context, not a captured host. Mousemove only updates hover geometry; it does not schedule slot-tree reads. The overlay clears on context changes, selection clearing, invalid reports, history viewing, deactivation, and disposal. Escape dismisses the rail and returns focus to the preview. Dismissal persists for the same host and context through geometry changes, mutations, and temporary offscreen visibility; a different selected host or context restores controls.

The overlay lives outside the iframe, clips to frame/pane viewport bounds, scales frame CSS pixels to editor pixels, and uses a wrapping rail with bounded height and vertical scrolling. The layer ignores pointer events; the rail accepts them so wheel scrolling and scrollbars work. Placement prefers the host's lower interior, then free clipped nearby space, avoiding actual edit-bar, insert-plus, card-add button and card-dialog rectangles at the existing z-index 8. If no free rectangle exists, the rail hides rather than overlapping controls. It neither inserts DOM into the page nor changes light DOM/source indexes. Runtime reporting stays in the editor preview runtime; exports need no ghost HTML, CSS, or editor runtime.

- Start Vite on `127.0.0.1:5446`, then `npx playwright test -c tests/slot-ghosts/playwright.config.ts`; stop that server afterward.

The browser fixture uses the actual `createNativePreview` and sandboxed native runtime. It checks assignment/fallback, hidden and zero outlets, name deduplication, instance callback, light DOM preservation, frame scaling/clipping/hit testing, invalid reports, selection changes, Escape, refresh, disconnection, and disposal. Coverage includes actual edit-bar/insert/card controls, physical button hit tests and overlap checks near frame top/bottom, a 390px 20-slot fixture with wheel scrolling and Tab order, instrumented slot-tree read counts for event bursts, assignment flips, first-outlet assignment, route/refresh stale callbacks, nested and standalone templates, vertical clipping, dismissal persistence, and disposal. Root source mutation and Undo require later integration tests. The pre-existing ordinary-empty `data-if` semantic bug also affects the published loader; this leaf does not fix it.
