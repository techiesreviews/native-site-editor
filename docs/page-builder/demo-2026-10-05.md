## Suggested review

1. **Page editing.** Select text in the canvas or Structure. Edit the page, change its text preset, and Undo. Drag or click the Code and sidebar grips: Code can disappear completely, and Style folds to the right.
2. **Style and CSS.** Select a classed element such as the Home lead paragraph. Review its class chip and stylesheet, search for a setting, and try a CSS variable with `--`. Check that visual changes produce ordinary CSS and Undo restores them.
3. **Add a section.** Use Add beside Page structure and choose Intro, Features, Split or Contact. The result is literal section HTML with native CSS. One Undo restores the whole operation, including its editor metadata and stylesheet changes. Split starts with a visual placeholder.
4. **Collections.** Select a Recent work card, open Collection, and choose pages from folders. Additional existing folders can join the same grid. Convert records the recipe in `.editor/page-builder.json` and writes complete cards into the page. Compare Edit page data with Edit collection, then Undo. The high-resolution mixed-folder capture includes a service page added by that test; the unmodified starter initially has work pages.
5. **Shared editing.** On About, hover a whole section, header or footer in Structure and use Save shared. Editing its page copy remains local. Explicit Edit opens its master; Done returns to the page. Use here links only the chosen copy. Update copies changes pristine linked copies and keeps customised copies intact; each operation has one Undo.
6. **Images.** Select an existing image to try Choose image, Alt text and Image focus. An ordinary `<img>` can also be added through Code. The current starter pages primarily contain text; the shared-header image capture uses an image inserted by its test. Image focus writes native `object-position` CSS.

Public website files remain ready HTML/CSS. Optional shared data, recipes and master files live under `.editor`; public pages render without it and without executable JavaScript. Existing Web Component sites retain compatibility.
