## Suggested review

1. **Page editing.** Select text in the canvas or Structure. Edit the page, change its text preset, and Undo. Drag or click the Code and sidebar grips: Code can disappear completely.
2. **CSS.** Select a classed element such as the Home lead paragraph. Review its rule chips and stylesheet in the Source editor. Edit CSS and check that Undo restores it.
3. **Cards.** Add card copies ordinary markup in a static grid. It can create a linked page in the same Undo step.
4. **Images.** Select an existing image to try Choose image and Alt text. An ordinary `<img>` can also be added through Code. Edit native `object-position` CSS in the Source editor.
